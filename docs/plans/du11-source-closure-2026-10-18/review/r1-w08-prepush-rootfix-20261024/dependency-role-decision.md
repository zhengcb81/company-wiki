# 依赖按用途计量：ROOT架构决策

原独立说明保留不动；其家具特例不能进一步变成“只有家具可作结构证明”的新限制。本轮ROOT先后提出过“全部物理见证占模型额度”“含业务文字的结构见证必须全文入模”，两项均撤回。

依赖的用途决定责任：业务父级、intro、脚注、限制、声明和指代等真正影响事实含义的材料，仍完整联合受原8units/4blocks/2048字符约束。独立完整的前一业务条目若只证明列表标记、缩进、栏位或跨页衔接，其无关数字无需自动进入下一条事实的模型上下文；真实ID、定位、边端点、略过见证及解析工作仍保留。同一ID若同时有语义责任，结构标签不能消除该责任。

共享物理producer观察一次；sections独占业务/列表父级；reading负责语义闭包与模型材料额度。内部typed transport只带来源与边信息，不另建身份/许可边界，不逐card重算几何。缺失、异源或明显不成立的证明有诊断；不得把真实脚注或负向限制藏成结构证明。

这是一项实现中的职责澄清，不是最终独审通过。源码冻结、自然测试包、独立大节点审查、真实年报回放仍待完成。原9期待、原RED、原8/4/2048均不改。
