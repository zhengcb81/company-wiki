## A. Necessary physical contract, not semantic proof

1. **Positive source coverage, source-only opt-in.** `DocumentStructure.coverage_complete` checks errors, opaque/deferred pages and page counts. A bare `pages_read == page_count` or `block_char_start == 0` is insufficient. Preserve actual ordering/coverage and pipeline truncation/nonselectable barriers. Full coarse-source coverage is distinct from all pages having fine geometry: pair-specific measured frame/font/column must still exist. The new optional flag must not silently alter legacy direct callers or manufacture observed pages.
2. **Exactly adjacent physical pages and positive body-lane evidence.** Same real source, compatible measured coordinate frame/rotation/dimensions/font and source role/section/profile/project scope; explicit valid nonnegative integer (not bool) or bounded nonempty string column IDs, equal in the same source reading model. `None == None`, bool/int equality, matching margins, or `no_column_gap` are not lane proof. Use true source-order last/first body members, not first/last of a prefiltered eligible list. An unowned table/QA/header/new chapter/project in between cannot disappear by filtering.
3. **Furniture is actual evidence.** `structure.__init__` emits `REPEATED_RUNNING_HEADER` only from `ordering.running_header_ids`; `coverage.excluded_furniture_unit_ids` unions those IDs with TOC IDs. Intersect skip IDs with the actual diagnostic and source units. Validate every intervening observation in original order belongs to the two involved pages and is a proved running-furniture ID; no blanket exclusion union, missing IDs, or arbitrary header/footer role. Keep skipped IDs in the edge proof. A running header does not itself prove no other missing body existed.
4. **Physical continuation and independent new statements.** Left must be a real pending nonterminal run. Right must not be an explicit fresh issuer assertion; source policy can pass an already-derived conservative boundary veto, instead of introducing a second business classifier in geometry. Existing `independent_subject` in `narrative_reading` is narrower than all explicit subjects, so tests need English/Traditional as well as one Chinese issuer fixture. Refusing a join must not automatically withhold a genuinely independent right statement. Conversely unknown dependency cannot gain closure because the next page begins at block offset zero. Physical proof must continue to state `semantic_status=not_evaluated`; it does not resolve product pronouns.
5. **Original multi-span support.** Cross-page windows carry each original ID as support, not context and not a new cross-page `native_page_view`. Carrier replacement may combine only per-page exact ranges; the resulting group must still carry every actual member. Groups must replace overlapping old owners rather than allow last-owner-wins. Required context, if later proved by the operating-state owner, retains its own original namespace and collective scope. The unchanged public citation limit/caps remain authoritative.
6. **Atomic resource closure.** Count original blocks by `(source_id,page,pdf_block)` and original units/chars including necessary context. Over 4 blocks/8 units/2048 chars means the whole dependent assertion is deferred, including the right suffix. Selecting only one original span under a one-span final budget must produce no partial statement. A complete independent next-page assertion is a separate control; do not restore the rejected HK rule that all unterminated singleton blocks are incomplete.

## B. Concrete required implementation controls found in current source

### B1 — Cross-page deferred ranges must be per actual page

Current `_Analysis.defer(run)` emits one `source_id`, **`page=run[0].page`**, and first/last global ordinal. Current `_prose_reading_packages` then indexes ranges by `(source_id,page)` and consults each observation's own page. Once a run spans pages, this representation would omit the right-page suffix (and can cover unrelated units on the first page). Do not merely enable a cross-page edge and retain this helper unchanged.

Minimal repair: within the same bounded run, group actual members by source+physical page and emit a range for each real contiguous page-local sequence; preserve all original IDs and complete range coverage. The 128 `deferred_unit_ids` examples must never become the authoritative blocker. `emit` currently uses `page=run[0].page` too: retain it only as an explicitly documented first-page compatibility field and add/use actual per-member/proof pages for multi-page meaning, or otherwise avoid a misleading single-page interpretation.

RED: one pending run with >4 distinct `(source,page,block)` across two pages, enough later units to make wrong-page blocking visible, and one-span/max-work failures during carry. Assert every dependent member on both pages is blocked, unrelated independent neighbors are not, and no original/citation locator changes. The current `test_cross_page_original_blocks_cannot_hide_over_limit_by_restarting_numbers` is valuable and must remain, but it does not isolate wrong-page ranges by itself.

### B2 — Metadata reservation must cover memberships, not only unit/package counts

Current `_candidates` precharges `4*len(parsed.units)+len(packages)+1`. However `_prose_reading_packages` iterates every package member into `owners`, every section heading/body membership, updates each body's heading set, iterates observations, and builds provenance. `other_members | excluded` is currently rebuilt **inside each observation loop**, so a large excluded/other set causes repeated set work not represented by that linear charge. The proposed cross-page/furniture preparation must not add further free scans after a tiny funded reservation.

Minimal repair in existing owner: precompute the union once; reserve/charge each actual package/section/furniture membership before traversing it, and charge bounded loop/index work using the same parent (or its phase scope). Avoid a second full classification or quadratic per-heading/body work. Direct private `_prose_reading_packages(...,work_budget=0)` also currently constructs its dictionaries/views before native charging, while the current zero-parent test only covers the public `_candidates` entry and observes `.native`. Either enforce charging in the common helper or explicitly keep the public entry as the only bounded entry and test all work there; do not claim arbitrary direct helper calls are zero-work.

RED: positive-but-insufficient parent, repeated large package membership with few units, many actual section memberships, and an observation/lookup spy that detects iteration before a reservation. Preserve successful phase accounting equality and parent not exhausted by a local 2-unit ceiling. This is accounting/efficiency correctness, not a request to increase the budget or replay real PDFs.

### B3 — Pre-charge and partial-state boundaries

`_Analysis.charge` correctly adds child.used only after successful parent charge; `work_units` is a phase delta, not global parent usage. Retain nested-scope tests with nonzero parent.used and an already-exhausted parent. In `build_native_continuity`, section ID tuples are materialized before `state.charge(1+len(ids))`; new code should not expand unbounded membership containers before a successful charge. On failure, retain `unexamined_from_index`, defer all known pending carry members, and ensure `_candidates` returns incomplete rather than restarting the remaining work with a fresh account. The current return already includes `continuity.complete` in aggregate completeness, which is correct.
