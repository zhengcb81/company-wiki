## 系统性判断

合法 support IDs、完整任务覆盖和 finite 语义诊断解决不了新增关系的蕴含：模型可在合法 support 下，从 question context 搬入关系谓词、为代词生成过宽前提、或把口径解释写进公司事实。局部来源、程度和条件必须随每个独立条目保留；只提高 prompt 的强调程度不能证明其可靠。
