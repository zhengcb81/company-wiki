## B首例实际观察（非生产验收）

冷SDK import107.051秒、首次转换11.448秒、同进程暖转换3.6483秒；父进程总耗时127.965秒、采样进程树RSS峰值1,058,410,496字节。由此不能每份文档重新冷启，也不能直接设为生产默认。原件/config/catalog未变，0 API/下载/付费/原件副本，自有临时目录恢复不存在。证据：docling-hk13.json及docling-hk13-execution.json。下一步比较疑难业务页的收益、来源忠实性和总成本，再决定最小复用适配。


## 用户要求的单层封装（2026-10-25）

解析/分解/证据定位/阅读策略/摘要编排属于一个逻辑文档阅读子系统，内部可分模块与适配器；引擎选择、能力探测、模型/版本/options、字节→坐标、回放和派生身份只由该层负责。存储层只提供已验证原件及持久化接口，调度层只提供任务/统一资源预算，RF等消费者只读统一产物。上层不得按具体函数identity决定传预算/上下文，不得挑引擎或解释其私有坐标。先真实对照再选型，接口测试须证明换实现不改变上层调用与共享预算。


## B完成后的准确结论

当前共享阅读在显式partial五页视图的八项叙述组检查6/8通过，Docling段落8/8完整；不是原生0准确率。当前缺组为行业云收入/增幅/原因与招股技术应用闭包，所有目标atoms已存在整体选材。经营应用同组文字保留，但当前selection无typed row/cell；原生强制按页发现表格的能力不能代签生产选材。详见decision.md及独审。
