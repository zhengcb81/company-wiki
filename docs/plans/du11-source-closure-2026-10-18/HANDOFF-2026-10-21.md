## 4. 关键决策与不变量（后续改动请遵守）

1. **mypy 配置保持**：`follow_imports = "skip"` + `check_untyped_defs = true`。
   单文件跑和全包跑结果可能不同，**以 `mypy src` 为准**。
2. **动态异常属性是跨层协议**：`capture_id` / `capture_receipt` / `acquisition_usage` /
   `provider_started` / `error_code` 等挂在原始异常上，保留异常类型供上层分类。
   读写一律 `setattr/getattr(exc, "name", default)`，不要改成强类型包装。
3. **形状收窄用 TypeGuard**：`_sequence`（PDF 快照）、`_is_index`（表格 slot）、
   `is_int`（几何 page 数）。不要用 `cast` 掩盖真实校验。
4. **只读 Protocol 字段用 `@property`**：frozen dataclass 无法满足可变协议属性。
5. **SQLite Row 不等于 dict**：需要 dict 语义就显式 `dict(row)`；`fetchone()` 要 None 守卫。
6. **argparse 子类 `error()` 返回 `NoReturn`**。
7. **平台专属 API**（`os.killpg/getpgid/setsid/sysconf`）只允许在 POSIX 分支，
   使用定向 `# type: ignore[attr-defined]` + 注释；不要全局放宽。
8. **禁止 `import fitz`**：统一 `import pymupdf as fitz`（stdout 污染）。
9. **PyMuPDF 上限 <2.0**：2.x 的文本/表格提取语义变化未适配；升级是独立课题
   （需重做 PDF 布局/表格收据）。
10. **文档-only 提交不触发 CI**（workflow paths-ignore），但会走 pre-push gate。
