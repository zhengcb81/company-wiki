# 三市场固定回归套件实施细则

## 固定对象与结论边界

中微 688012（CN v3）、腾讯 00700（HK v4）、微软 MSFT（US v2）；as-of=2026-10-08。以已封存独立审查为事实基准，按输入/原件 SHA 固定样本。固定模型输入用于计算与证据合同回归，不声称重新完成一轮人工研究或证明情景预测准确。新摘要与旧模型的实际消费要单列，不以“文件存在”代替消费。

## 施工顺序（只有三个验收节点）

1. 写轻量单元测试：失败/阻塞/未跑不可合并为 PASS；不同样本、模式或检查定义不可宣称改进；路径逃逸拒绝；故障也清理；5pp=0.05、同行风险不得给本公司增长增加正向三角验证、无年份达产目标不得补年、季度 CC 指引不得年化。
2. 实现 `tools/cross_market_suite/` 与 `benchmarks/cross_market_rf/`。工程 CLI 只读邻仓，导出指定 commit 的代码到临时环境，避免 owner WIP；RF registry、原件副本、CWP catalog、AUTO/work/output、HOME/缓存均隔离。普通模式不携带真实密钥，不联系公网。
3. 固定清单列出输入/最终结果/快照/审查 SHA、全来源原件 SHA、原始市场/期间/日期限制和关键事实。原件从现有 RF 内容寻址交付或只读 CWP reader 获取；不重复把几十 MB PDF 放 Git。缺样本为 BLOCKED，不跳过后伪称成功。
4. 每公司实际注册、重复注册、搬移存储后 SourceRef 读取、坏 hash 拒绝；真实 RF→FF→CWP 原件复用入口；原件文本/页数检查；正式 validator→engine→Markdown→snapshot→registry audit；独立桥接/敏感性计算与固定领域检查。未知公开日、图片型 PPT、HTML 支持分别显式记录。
5. 跨仓包运行现有 FF→ET→CWP 离线验收（真实 CLI/worker/import，仅 HTTP 回放），以及真实原件有限 Worker→NarrativeRef→RF 消费接口。模型回放证明流程与定位，不证明外部模型摘要质量。记录翻译关闭、跳过套话、再次运行零新模型请求、超时清理。
6. 在线模式在同样隔离环境走真实 RF→FF→市场 provider，按固定缺文档请求、实际 byte/time/cost 限额和供应商配置执行；复用第二次请求，留 FF envelope/provider_calls。Dayu 无预算、ET 套餐不支持、未知日期为具名 BLOCKED；官网人工补抓不能让正确路由检查 PASS。默认不做收费生成；真实摘要刷新沿既有配置/预算另在大节点执行并独立审查，不重置累计账。
7. 写 JSON/Markdown 检查点矩阵与比较命令：只对相同样本/模式/检查定义比较；记录版本与执行模式；FAIL/BLOCKED→PASS 才是能力修复，性能比较须相同输入/模式，不凭速度认质量提高。未运行、人工结论、未来回测不可伪造为自动通过。
8. 验证三公司当前基线；重跑对照；故障注入验证清理及生产只读保护。仅留轻量报告和命令摘要，不保留重建中间数据。最终更新 PWF、提交推送。只有小型 runner 单元测试进普通 CI，真实样本/跨仓套件手工大节点运行。

## 检查点目录

详见 `benchmarks/cross_market_rf/README.md` 与 `checkpoints.json`。至少覆盖：环境/commit/安装来源、样本字节、来源身份/期间/as-of、正确市场工具和真实 FF 调用、缺文档下载与重复复用、电话会启动与套餐区别、PDF/TXT/HTML/PPT解析、业务精选与原语言摘要、span 原文定位、虚拟接口/物理移动、摘要实际消费、技能 0–11 覆盖与缺项、单位/口径/目标/同行/敏感性、正式产物链、快照不可变、费用/空间/清理。

## 独立复现与恢复

运行参数显式给 RF/FF/ET 根和固定交付目录。不得硬编码本机目录、修改生产配置/数据库/原件、修改 Dayu、执行邻仓未提交代码，或为通过删掉 BLOCKED 检查。生成的 test root 是随机独占子目录，退出/finally 恢复为不存在；调用失败仍留轻量 report。进程强杀无法执行 finally 时，下次仅按拥有标记清理明确 test root，禁止删除任意目录。报告输出不能在 scratch 下、不得覆盖历史基线。

大节点测试失败时先看 checkpoint 和命令的 stderr/returncode；只调整对应责任层。固定金额/单位/事实与公开日标准的变化须来源支撑，不能改 expected 来适应错误实现。生产目录、源资料和 owner WIP 应运行前后相同。
