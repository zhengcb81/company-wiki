# 阅读策略覆盖矩阵

“有 profile”“读过样本”“正确召回”“摘要真实可靠”分别记录。下表基于当前调查及交接，不是全量质量认证。所有经营量均保留主体、期间、单位/币种/分母、地域、实际/计划及必要条件；常规三表可由金融 API 提供，本模块不追求全文数字抽取。

## 文档用途与深度

| 类型/优先级 | 必读业务问题与区域 | 原子证据与防错 | 当前基础及补证 |
|---|---|---|---|
| A股年报 / P1 | 主营结构/行业变化、产品研发与商业化、客户订单、产销/利用率、海外、未来计划；MD&A、业务概要及业务附注 | 产品阶段与主体；存量/新增；风险发生事实与一般风险分开 | 中微真样本；需更多行业，摘要忠实度待测 |
| A股半年报 / P1 | 相对年初有什么变化、项目进度/下半年安排；不可直接复用年报摘要 | 半年累计非二季度；计划非承诺；未重复披露不等于取消业务 | 中微210页观察；需单独金标和无预期变化样本 |
| A股季报 / P1 | 重要事项/变动原因中的短业务进展；先完整轻扫再判断价值 | 财务表多仍可能有产品验证；无业务可0切片/0 LLM | 中微富业务、世华稀疏；先纠正错误财务召回gold |
| 港股年报 / P1 | 主席/CEO陈述、Business Review、MD&A、经营表、行业和业务相关notes | 中英对应去重；地域/门店模式、总数/净增、期后事件；不要盲套SEC Item | 名创真实双栏与门店表；几何恢复缺口未闭环 |
| 港股中期 / P1 | 本期变化、展望、期后重大业务事件；独立处理未审计状态 | 六个月/单季/期后分开；只提取与业务有关的数字解释 | 名创中报观察；与年报共用模板但周期不丢 |
| SEC10-K / P1 | Item1、7及业务风险/分部/合同附注；业务模式和经营驱动 | DOM标题层级、ix:hidden排除；收入确认描述可解释商业机制 | 微软/英伟达/MongoDB本地；已有HTML前端，observer需接正 |
| SEC10-Q / P1 | PartI Item2、业务附注、PartII业务风险更新 | 重复Item编号须保留Part层级；季度/YTD与同比基期 | VRSK有观察；真实完整策略/金标待补 |
| SEC20-F / P1 | Item4业务/组织、Item5经营回顾、Item3D具体风险 | 注册地/上市地/业务市场不同；10-K章节不能照搬 | TAL观察；组织结构不是经营KPI，监管影响需归因 |
| A股招股正文 / P1 | 业务与技术、客户/供应商/销售机制、行业口径、增长策略、募投用途/风险 | 发行时点历史基础；第三方行业估计≠公司实际；客户匿名不得猜名字 | 中微429页；业务与项目信息分包，不能只追近期变化 |
| 港股招股正文 / P1 | Business、Industry Overview、Future Plans/Use of Proceeds、竞争与客户依赖 | 繁英别名要合并；行业顾问估值/预测保留作者；未商业化产品需保留阶段 | 名创675页观察；组合别名实际丢失，先修 |
| US S-1/F-1及最终prospectus / P1 | Business、MD&A、Risk、Use of Proceeds；区分IPO/转售/其他发行用途 | 正式Form与交叉引用不同；旧股转售≠公司获得全部募集资金 | 控制实验当前generic；本地完整gold缺样，先补资料请求 |
| 定增/配售募集说明书 / P1 | 项目背景、产品/客户、产能、投资构成、分期建设/达产、许可、消化条件 | 项目甲属性不可并入乙；总/新增产能；预测收入/投资额/实际收入区分 | 恒锋跨页已揭示共因；不能只看募集金额 |
| 可转债/募投可研 / P1 | 现有业务与新项目关系、资金缺口、自筹/分期、建设和爬坡、技术/审批风险 | 债券条款一般降权；但影响项目融资或建设的条件须保留 | 金禾观察；原有500吨与拟1500吨等口径要独立 |
| 募投变更/延期/终止/进展公告 / P1 | 原计划→本次变化、原因、剩余承诺、对子项目的影响 | 延后≠取消；部分变更≠全部项目变化；没有旧版不得编delta | 当前泛generic；对第二曲线时效很重要，需补样 |
| 投资者调研记录/业绩说明会 / P1 | 完整Q+A/追问、管理层补充、明确否定、回避回答、主/子公司归属 | 问题设想≠公司事实；股东联系≠上市公司客户；不回答≠不存在 | 万润强例；cn-ir-policy实际也是活动记录，不能作制度负例 |
| 财报电话会 TXT/HTML / P1 | Prepared Remarks、Guidance、Q&A；发言者、管理层修正、统一口径说明 | 网站takeaways/分析师/管理层分开；constant currency等全局限定随局部事实 | 微软原语言TXT可复用；跨问答和统一口径依赖待强化 |
| 业绩新闻稿/股东信 / P1 | Business Highlights、各业务表现解释、产品/客户动态、展望 | 财务标题不应挤走业务；管理层说法有来源角色，数字保留口径 | 腾讯/微软观察；需真实摘要与重复事实控制 |
| 投资者演示/PDF/PPTX/图片 / P1 | 经营图表、产品路线图、产能/门店/客户组合、页内脚注 | 图题/图例/坐标轴/单位/时间随数据；缺图不可声称完整，不猜图上数字 | 腾讯deck及微软图像PPT已有调查/独立OCR能力；本轮未认证完整图表理解 |
| 8-K/6-K及附件容器 / P1 | 主表确定事项/附件清单，附件按release/deck/事件正文阅读 | 主件和附件不同SourceRef；同原件子范围才child_routes；未下载附件是needs_source | 已核官方真实目录；本地真实端到端仍缺；当前子策略未接 |
| 摘要/修订/补充/更正 / P1横切 | 本件覆盖范围、修改原因、变化部分及引用旧文的关系 | 不覆盖原始版本；摘要未提不等于全文没有；仅签字修订可合法无业务 | 设计有、路由轴未落地；需真实版本对 |
| 问询回复/重组收购/重大合同/经营事件 / P2 | 被询问的业务细节、履约条件、经营资产/产能、项目成本/计划、终止变化 | 不把监管问题当前提真值；合同额≠确认收入；收购对价≠资产经营收入 | 高信息密度，先通用event/response策略，缺样不编造 |
| 制度/会议通知/确认函/签章附件 / P1负例 | 核实正文是否真纯程序性，是否包含经营议案/实质附件 | 不按文件名或空OCR跳过；确认无业务后只留来源和诊断 | 真扫描确认函可用；真正制度/通知负例需补 |
| 研报/新闻/政策/ESG / P2按需 | 与业务相关的新事实、约束/机会、具体产能或监管进度 | 公司披露/记者/研究员/政策发文主体不同；研究预测不得当公司承诺 | 当前通用策略；仅保留源信息，不在CWP生成研究结论 |

此清单表达支持范围，不要求每一格先绿才能上线。先修P1真实根因并通过代表形态，稀有缺样明确fallback/未测；不得把未知文档自动判为无价值。

## 跨文档共用的业务关注点

| 关注点 | 最小有用信息 | 必须一起带走的限定 | 典型误读 |
|---|---|---|---|
| 主业/商业模式 | 谁向谁卖什么、收费/交付/履约方式、本期进展 | 实体/产品、范围、时间、披露方 | GMV/RPO/订单直接变收入 |
| 行业/竞争 | 供需变化、替代技术、竞争方式及公司受到的具体影响 | 公司陈述vs第三方统计、样本/地域/统计期 | 行业预测当公司订单 |
| 新产品/第二曲线 | 开发→送样→验证→小批量→量产→规模化及证据 | 精确产品、阶段、客户范围、条件、实际/目标 | “验证中”说成已规模供货 |
| 出海/新市场 | 新地区渠道/工厂/许可/客户、实际进入程度 | 集团/子公司、地区、签约/执行、币种/统计口径 | 有海外注册公司就认定海外收入增长 |
| 客户/订单/履约 | 订单质量、交付、需求/转化、集中风险 | 可取消性、履约期、正式订单vs框架、客户身份保密 | 意向订单全部转成未来收入 |
| 产能/募投 | 现有/新增产能、建设/投产/爬坡、利用率 | 项目、单位、分期依赖、资金/审批条件、测算口径 | 建成等于达产，拟投等于已投 |
| 经营指标 | 店数/同店、用户/留存、消耗、台数/认证等 | 存量/流量、分母、期间、地域、直营/加盟等范围 | 总数当净新增，用户当付费客户 |
| 约束/风险/否定 | 延期、取消、监管、技术/客户限制、管理层明确否认 | 实际发生vs假设风险、否定作用域、时间、主体 | 套话风险当新事件、问句当事实 |

经营模式修饰只深化解释：软件区分订阅/消费和队列指标；零售区分门店模式/同店；制造区分认证/产能/利用率；生物医药/CDMO区分研发临床商业化、里程碑/版税及产能订单。模板缺字段时标未披露，不要求LLM补齐，不增加完整财务模型。
