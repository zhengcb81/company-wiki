# S1–S5 独审整改与复验

## 范围与完成条件

按 [独审报告](../review/s1-s5-independent-20261125/findings.md) 的 12 仓和 F4 宿主执行。优先修复会污染产物、重发有外部副作用的请求、丢失业务结果或泄露敏感信息的缺陷。同时补足各仓的公开运行生命周期、职责边界和日常回归。分仓保持原配置、公开兼容接口和在途修改，具体兼容影响在验收时记证。

每个分仓候选须实现已复现缺口的共用根因修复，提供先红后绿的回归、公开入口冷读、人可复跑的命令和文件清单，并由独立 agent 对最终候选复审。若发现缺口，责任仓继续整改。总控再测原运行号的组合冷读、并发/强停、外部请求次数以及所有记录介质不可用时的诊断。全部通过才关闭本计划。受验代码和实施记录按本仓发布流程处理。
