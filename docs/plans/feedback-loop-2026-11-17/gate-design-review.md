# 公开接口与存储的门禁审查

2026-11-19。组合验收中，IQS 已交付可读的聚合资料，Dashboard 因 `company_assessment/1.0.0` 精确匹配把 `1.1.0` 返回为 503。对七个仓库的相关公开入口做了定向审查。此页登记实际组合、历史重放和离线模拟的证据，供本仓现有计划接续。

## 实现规则

1. **在公开入口定义兼容性。** 使用构建号定位运行记录。读取同一协议家族、同主版本的兼容发布时，适配器取实际依赖的字段并验证身份、期次、类型和必要能力。增量字段由消费方投影，新的业务含义通过显式能力或协议声明。版本解析由各自适配器统一实现。实际不兼容时返回具体协议或缺失能力，允许通过公开适配器升级。
2. **按动作验证前置条件。** 打开原件由 CWP 验实际字节、SHA、来源身份和时间。账本由作业 owner 核对原作业、尝试、费用和限额。查询原结果、复用原件、恢复已结算结果使用已有证据。下载、转录或发起新付费才进入相应资源预算。费用未知可用原作业账本继续对账。
3. **让诊断伴随结果。** review、构建标签和可选追踪数据缺省或无法解释时显示未知。业务结果由其责任层判断。资料完整、页码、出处和原始收据可独立读回。大报告在展示层分页，完整结果走流式输出或现有下载接口。实际计算图、运输、磁盘及费用资源由对应执行层一次计量，重复的表现层阈值移除。
4. **明确哈希与版本绑定的对象。** 原文 SHA 对应未改写字节。封存投影 ID 对应完整、无歧义的规范化内容。可用的空白、键序和转义经过正常解码后收敛到同一个 ID。含义随算法改变的封存产物按记录的算法重放，解析器所有权留在生产者。关闭反馈问题的复验收据绑定实际修复源码。

## 组合复验

本仓 TDD 先令同一已验结果仅改变兼容发布号、增加扩展或调整排版，核对 ID、业务值、用量及已有作业数相同。然后改变实际身份、期次、散列、schema 含义或付费动作，核对返回具体原因和实际写入或启动次数。对超长合法输出核对就地读回全部证据，对真实资源超限核对一次计量和保留进度。

总控已有 StockWiki → IQS → Dashboard 正式登记黄金样本及 FF → CWP 原件复用样本。按现有大节点复跑受影响链，关键节点独审。测试使用独立临时根。现场日志登记原原因、真正负责的入口、可重放最小输入和修复版本，后续复发沿本仓既有反馈工作流处理。
