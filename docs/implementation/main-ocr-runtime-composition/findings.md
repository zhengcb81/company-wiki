# Findings

## Shared causes

The old routing used universal normalization 1.0 for PPTX, although the actual parser dependency provides pure 1.1 and OCR 2.0. Selection rejected every opaque page, while replay interpreted historical locators with the current parser and required exhaustive source coverage. Runtime/factory had no immutable normalization port. These causes blocked reliable selected OCR derivatives and historical pure replay.

The real scoped builder also advertised binding/3 without generation metadata. That was an invalid producer contract, so resume refused before checking frozen membership. Legal old scoped builders now produce binding/2; real complete manifests produce binding/3. A declared malformed binding/3 still refuses. Three versions observe current read facts without re-signing frozen source/model/pricing/accounting identity; changed job hashes retain their named membership refusal.

## Composition

One process-owned `NarrativeNormalization` freezes configuration; only PPTX consumes OCR. Pure parser use has no configuration requirement. Causal identity is pathless and actual per-format/version. Config snapshot identity must match each frozen OCR manifest; each selected OCR locator fingerprint must match that manifest after actual public replay. Both mismatches were reproduced as genuine RED before correction.

Original language uses actual native text, then at most three unique image samples. Current OCR replay validates model SHAs and current fingerprint and calls the parser dependency once for all selected locators, with one inference per selected unique media. Historical pure 1.0/1.1 dispatch never initializes OCR. Low-confidence/unstable candidates are excluded; source coverage, opaque pages, OCR recall and layout limitations remain visible. Reliable partial selection with completed summary reuses its complete derivative; exhaustive empty skips retain full-coverage requirements.

## Verification limits

Offline adapters exercised actual tiny model SHA files, actual owned PPTX image bytes and actual parser/replay API, without loading ONNX or contacting a supplier. HTML/PDF/TXT integration used public configured finite CLI and a loopback model; each source caused one local POST total across distinct runs. Actual installed OCR configuration/runtime/22-page major-node validation belongs to MAIN and the parser owner.

RF source_preparation currently caps publicread timeout at min(remaining,30 seconds). Large selected OCR media sets may require longer replay; MAIN owns that downstream correction using its actual remaining deadline.
