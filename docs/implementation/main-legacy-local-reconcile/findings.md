# Findings

## Root cause

The active-only query correctly refuses retired documents, but composition previously treated that miss as permission to fetch. Metadata-only retirement also preserved wrong legacy issuer/FY declarations. Same-byte official imports skipped source-facts correction on dedup. A trustworthy local original must enter explicit source preparation before acquisition, then return through ordinary query/read eligibility.

## Responsibility repair

- `local_inventory` observes exact source/locations/audits and verifies inactive registered bytes with existing root, SHA, size, placeholder and bounded read guards. It does not fabricate an active read handle.
- Metadata retirement uses an exact known producer/reason chain, including the original Phase15.6 reason before reconciliation. Unknown, withdrawn, damaged and conflicting history remains ineligible.
- SEC facts come from actual DEI, verified active security identity and existing hash/size/primary/accession-bound local `meta.json`. Request/filename/mtime does not supply FY or publication. Unknown URL remains null.
- `restore_document_facts` verifies under the existing catalog lock, replays facts and optimistic observation, and writes correction/projection/eligible locations/restore audit in one existing SQLite transaction. Prior retire audits remain. Four injected write failures roll back the entire operation.
- Explicit `local_prepare_cli` and ensure composition use this service. Default source-query remains read only. Genuine absence retains existing acquisition semantics; a local metadata/read gap blocks provider discovery/fetch.
- Same-byte local official imports correct facts semantically and idempotently. They refuse non-metadata retirement. Explicit provider re-download keeps the previous canonical-writer contract; this package does not redefine provider withdrawal policy.
- Unindexed discovery is finite and issuer-scoped in configured company_raw/dayu_portfolio layouts, then delegates to existing source-group registration. Generic directory roots can use explicit registrations; no whole-root rescan.

## Real counterexamples fixed without weaker assertions

Actual FF recursively forbids physical output keys: internal verified_locations counter was removed from the public operations DTO. Actual SEC inline markup produced `10- Q`; canonical form normalization removes whitespace while preserving amendment `/A`. Generic offline REDs cover both.

Caller fixture errors are retained: absent owned PYTHONPATH, incorrect external root/unsupported transcript mode, and an UPDATE of all location roles that violated uniqueness. The old 32-span integration fixture used a removed private normalization symbol; MAIN authorized its migration to the shared normalization port with actual language, preserving 32 locators and one parse.

## Boundaries

The CN FY24 original remains retired with local_metadata_incomplete: no independent publication proof and insufficient bound issuer metadata. This is an honest 0-download gap. Registered current facts are distinct from historical availability proof; this package does not emit a capture/assertion/archive availability DTO. All original bytes, provider sidecars and production configs were protected and unchanged. No company/SHA special cases, model calls, provider calls, second DB or permission state were added.
