## 快速开始

### 1. 查看系统状态

```bash

# 或查看Markdown版本

```

### 2. 运行Pipeline

```bash
# 处理单个公司
python scripts/full_pipeline.py --company 中微公司 --limit 5

# 带Gate检查
python scripts/full_pipeline.py --company 中微公司 --limit 5 --gate-log

# 跳过Gate检查
python scripts/full_pipeline.py --company 中微公司 --no-gates
```

### 3. 运行测试

```bash
# 运行所有测试
python scripts/test_framework.py --suite all

# 运行特定测试
python scripts/test_framework.py --suite gate --company 中微公司
```

## Pipeline使用

### 基本用法

```bash
# 处理单个公司（限制5个文件）
python scripts/full_pipeline.py --company 中微公司 --limit 5

# 处理所有文件
python scripts/full_pipeline.py --company 中微公司

# 只运行特定阶段
python scripts/full_pipeline.py --company 中微公司 --stage analyze
```

### 阶段说明

| 阶段 | 脚本 | 功能 |
|------|------|------|
| Stage 1 | `stage1_extract.py` | PDF提取为Markdown |
| Stage 2 | `stage2_structure.py` | 结构化处理（财务数据、章节） |
| Stage 3 | `stage3_analyze.py` | LLM分析（配置驱动） |
| Stage 4 | `stage4_review.py` | 审查评分 |
| Stage 5 | `stage5_ingest.py` | 入库到Wiki |

### 常用选项

```bash
# 预览模式（不执行）
python scripts/full_pipeline.py --company 中微公司 --dry-run

# 跳过Gate检查
python scripts/full_pipeline.py --company 中微公司 --no-gates

# 显示Gate日志
python scripts/full_pipeline.py --company 中微公司 --gate-log

# 限制处理文件数
python scripts/full_pipeline.py --company 中微公司 --limit 10
```

### 配置驱动的Prompt

Stage 3 使用配置驱动的Prompt系统：

```bash
# 配置文件位置
config/analysis_frameworks.yaml   # 分析框架
config/prompts/*.yaml             # Prompt模板

# 支持的文档类型
- prospectus (招股说明书)
- annual_report (年度报告)
- semi_annual_report (半年度报告)
- quarterly_report (季度报告)
- investor_relations (投资者关系)
```

## Gate系统

### Gate列表

| Gate | 名称 | 功能 |
|------|------|------|
| Gate 1 | 提取质量 | 检查文本长度、质量分 |
| Gate 2 | 数据契约 | 检查必填字段、数值范围 |
| Gate 3.1 | LLM格式 | 检查JSON格式、必填字段 |
| Gate 3.2 | 幻觉检测 | 检查数字是否与原文一致 |
| Gate 3.3 | 逻辑一致性 | 检查营收/利润关系 |
| Gate 4.5 | 分析师审查 | 5维度加权评分 |
| Gate 5 | Wiki完整性 | 检查frontmatter、链接 |

### 运行Gate检查

```bash
# 带Gate检查运行Pipeline
python scripts/full_pipeline.py --company 中微公司 --gate-log

# 只运行Gate检查
python scripts/test_framework.py --suite gate --company 中微公司
```

### Gate配置

```yaml
# config/pipeline_rules.yaml
financial_report:
  gate_3_1_llm_format:
    enabled: true
    threshold: 4.0
    max_retries: 3
  gate_3_2_hallucination:
    enabled: true
    threshold: 5.0
```

### Gate 4.5 评分维度

1. **投资逻辑** (25%)
2. **风险覆盖** (25%)
3. **同业对标** (20%)
4. **数据质量** (15%)
5. **前瞻展望** (15%)

## 审核机制

### 审核流程

```
1. 运行自动化测试
      ↓
2. 检查测试结果
      ↓
3. 人工快速确认
      ↓
4. 记录审核结果
      ↓
5. 如有失败，暂停并修复
```

### 运行测试

```bash
# 运行所有测试
python scripts/test_framework.py --suite all

# 运行特定测试
python scripts/test_framework.py --suite unit
python scripts/test_framework.py --suite integration
python scripts/test_framework.py --suite gate

# 测试指定公司
python scripts/test_framework.py --suite gate --company 北方华创

# 生成测试报告
python scripts/test_framework.py --report
```

### 查看测试结果

```bash
# 查看最新测试结果
cat docs/test_results/latest.json

# 查看审核日志
cat docs/review_log.md

# 查看测试报告
cat docs/test_report.md
```

### 测试套件说明

| 套件 | 内容 | 超时 |
|------|------|------|
| unit | 单元测试 | 120s |
| integration | 集成测试（Pipeline端到端） | 180s |
| gate | Gate系统测试 | 180s |
| section_discovery | 章节发现测试 | 60s |
| framework_loader | 框架加载器测试 | 60s |

## 信息熵减工具

### 1. 自动综合触发器

当公司时间线条目超过阈值时，自动触发综合评估更新。

```bash
# 检查是否需要综合
python scripts/auto_synthesis.py --company 中微公司 --check

# 预览综合
python scripts/auto_synthesis.py --company 中微公司 --dry-run

# 运行综合
python scripts/auto_synthesis.py --company 中微公司 --run
```

**配置**:
- 阈值: 50条时间线条目
- 输出: `companies/{公司}/wiki/综合评估.md`

### 2. 信息过期追踪

标注和检测时间线条目的信息有效期。

```bash
# 检查过期条目
python scripts/expire_tracker.py --company 中微公司 --check

# 生成过期报告
python scripts/expire_tracker.py --company 中微公司 --report
```

**信息类型和有效期**:

| 类型 | 有效期 | 说明 |
|------|--------|------|
| 订单 | 365天 | 订单/合同 |
| 业绩 | 90天 | 季度业绩 |
| 财报 | 180天 | 半年报/年报 |
| 政策 | 730天 | 行业政策 |
| 技术 | 1095天 | 技术突破 |
| 人事 | 365天 | 人事变动 |
| 融资 | 365天 | 融资/IPO |
| 风险 | 180天 | 风险事件 |

### 3. 核心问题动态进化

LLM建议新问题，人工审核后采纳。

```bash
# 列出当前问题
python scripts/question_evolver.py --company 中微公司 --list

# 建议新问题
python scripts/question_evolver.py --company 中微公司 --suggest

# 生成审核清单
python scripts/question_evolver.py --company 中微公司 --review
```

**流程**:
1. LLM基于时间线建议新问题
2. 生成审核清单到 `docs/question_review_{公司}.md`
3. 人工审核并选择采纳
4. 更新 `companies.yaml` 的 questions 字段

## 投资估值

### 估值引擎

```bash
# 预览估值
python scripts/valuation_engine.py --company 中微公司 --dry-run

# 运行估值
python scripts/valuation_engine.py --company 中微公司 --run
```

**估值维度**:
1. PE估值（基于行业平均PE）
2. PB估值（基于净资产）
3. DCF估值（基于未来现金流折现）
4. 同行对比
5. 催化剂分析（短/中/长期）
6. 风险因素
7. 投资建议（看多/看空/中性）

**输出**: `companies/{公司}/wiki/投资估值.md`

```bash

python scripts/audit_config.py --scan

# 生成审计报告
python scripts/audit_config.py --report
```

### 修改Prompt模板

编辑 `config/prompts/{文档类型}.yaml`：

```yaml
template: |
  你是一名资深分析师。请分析{company}的{period}报告。
  
  ## 分析框架
  {framework_description}
  
  ## 输出格式
  {output_schema}
```

### 添加新公司

1. 在 `companies.yaml` 添加公司信息
2. 创建 `companies/{公司名}/` 目录
3. 放入PDF文件到 `raw/` 目录
4. 运行Pipeline

## 故障排除

### 常见问题

#### 1. Pipeline运行失败

```bash
# 检查错误日志
python scripts/full_pipeline.py --company 中微公司 --limit 1 2>&1 | tail -50

# 预览模式检查
python scripts/full_pipeline.py --company 中微公司 --dry-run
```

#### 2. Gate检查失败

```bash
# 查看Gate日志
python scripts/full_pipeline.py --company 中微公司 --gate-log

# 检查具体Gate
cat docs/test_results/latest.json
```

#### 3. LLM调用失败

```bash
# 检查API配置
cat config.yaml | grep -A 5 "llm:"

# 测试LLM连接
python -c "from llm_client import LLMClient; print(LLMClient().generate('test').content)"
```

#### 4. 编码错误

```bash
# Windows设置UTF-8
set PYTHONIOENCODING=utf-8

# 或在命令前加
PYTHONIOENCODING=utf-8 python scripts/...
```
