# 公司来源平台使用入口

company-wiki 保存上市公司原始资料、来源版本和 SHA，按需规范化与解析业务叙述，提供可定位检索、预览和只读 export。来源文件的实际目录由存储层处理，下游使用 SourceRef / SourceExport v2，不直接操作来源库文件。

## 当前用法

先查看已经安装的公开入口帮助，参数以当前 CLI 为准：

```text
company-wiki-source-catalog --help
company-wiki-source-read --help
company-wiki-source-query --help
company-wiki-source-export-v2 --help
```

- [来源目录与下载/登记/检索接口](source-catalog.md)
- [运维与配置](OPERATIONS.md)
- [总计划与当前实施状态](plans/narrative-evidence-pilot-2026-09-26/task_plan.md)

叙述处理仅运行明确的有限批次并遵守已配置模型、token、费用、时间和空间预算。原始财报、招股/融资文档、投资者关系记录和电话会 TXT 保留原语言；纯流程文档可跳过模型摘要，表格金融数据由下游工具取得。测试和真实运行目录分开，测试新增资料结束后恢复原状。

## 已退休入口

旧 `full_pipeline.py` 与 Gate0–5 整族已退休；旧金融/Wiki writer 不作为新处理入口。无需签收、审核或配置旗标来恢复它们。旧维护删除命令也已退休，清单仍可只读查询。投资评估、目标价、估值和研究结论属于 StockWiki。

开发时只测试改动涉及的职责，大节点做集成和端到端测试；正常提交保留便宜静态检查，推送与 CI 使用当前短集合。无需每次会话重新运行旧全套流水线或整库恢复演练。

旧版本完整说明保留在 [Git 历史](https://github.com/zhengcb81/company-wiki/blob/7fb29b94e8fd5c4584963b846714bafdc1f63baf/docs/使用说明书.md)，不产生新的执行要求。
