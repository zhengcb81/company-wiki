# Company Wiki 核心模块质量整改

## Goal

按生产责任逐个审查七个核心模块。修复可复现的架构、泛化、冗余门禁和测试问题。保持已有原件、历史产物和公开协议的可用性。

## Current Phase

### Phase 1. 盘点与独立审查

**Status:** complete

- `source_contract` 管来源身份、定位、清单和版本。
- `document_model` 管载体无关的结构、说话人和匹配值。
- `parser_adapters` 管本地原件解析后端及其适配。
- `document_normalization` 管原文规范化、定位回放和可选 OCR。
- `document_understanding` 管文档路由、结构理解、阅读策略和摘要输入。
- `source_catalog` 管来源采集、存储、检索、证据选择和复验。
- `automation` 管调度、并发、预算、模型、发布和恢复。

### Phase 2. 各模块实施

**Status:** complete

各模块由一位作者在独占范围内工作。先做能复现实际问题的测试，再从共用原因修复。保留字节、来源、原件可回放、事务和配置预算等各自责任层的正确性要求。表示或可选诊断不得挡住有效业务结果。共享接口确需调整时由总控协调，优先在原模块内修复。

### Phase 3. 组合验证与复核

**Status:** complete

各模块测试与静态检查完成后，重点验证公开接口、旧数据和正式工作流。独立复核改动及测试是否准确覆盖根因。记录实际验收范围、剩余问题和当前工作树状态。

| 边界 | 代表性验收 |
|---|---|
| 来源合同、文档模型、解析后端 | 合同值往返与版本兼容，禁止加载上层的独立进程，原文定位及后端替换。 |
| 规范化与理解 | 各载体的原文回放，配置外的市场或文种，跨阈值表格和实际工作上限。 |
| 来源目录 | 临时目录和 SQLite 内的本地复用、来源状态、缺失下载、故障重试及原件保留。 |
| 自动化 | 零模型路径，预算超限，本机模拟模型的发布、恢复和历史产物读取。 |
| 总控组合 | 依赖方向、跨仓公开接口、源码静态检查，以及本轮改动实际影响的端到端场景。 |

### Phase 4. 遗留闭环与主线发布

**Status:** in_progress

1. 来源采集复用由来源层一次完成候选严格验真，并在同一次事务内消费收据。锁内发现的新状态继续实时验真。
2. PPTX 分开记录可用正文和整页素材覆盖。现有引用可以重新定位，空产物需要实际覆盖证明。
3. SourceExport v1 区分物理拼写和 Unicode 等价。精确定位和 SHA 绑定继续由清单层负责。
4. 总控从远端 `master` 的 `8934b49c2` 构建隔离发布候选。核对实际代码依赖、历史产物及组合测试，独立复核后提交并正常快进推送。Dashboard 待并提交和本地运行产物留在各自工作树。

## Next Step

三个遗留均已定点修复。采集、摘要与缓存、RF 和 FF 的组合验收已通过。首个发布候选的 CI 发现旧测试接线与 Phase C benchmark 入口问题，按责任层修复后验证新候选，再快进远端 `master`。

## Decisions Made

| 决定 | 理由 |
|---|---|
| 独立的 PWF 目录 | 既有计划与外部项目可以继续使用其原入口。 |
| 审查按现有生产边界分工 | 源码写入范围独占，共享测试与接口由总控协调。 |
| 保留当前工作树的已有改动 | 基线包含尚未提交的解耦和其他工作。只叠加本轮必要变更。 |
| 使用隔离夹具和本机回放 | 可重复地验证正确性和恢复，隔离原件、生产配置与外部供应商。 |
| 各模块单独验证，相关模块冻结后做组合验证 | 缓存身份会读取当前代码，组合测试应在稳定版本上核对。 |
| 从远端主线创建独立发布工作树 | 本地 `62602102a` 含 Dashboard 待并提交，本轮与其他未提交工作也共享部分路径。只发布已验收的分层改造和依赖，保留原工作树与暂存状态。 |

## Errors Encountered

| 情况 | 处理 |
|---|---|
| 带 `-CheckAmbiguity` 的 PowerShell 探针不返回计划路径 | 改用显式 `PLAN_ID` 和 `PWF_PLAN_ROOT` 调用解析器的普通模式，已核对三个文件。 |
| 沙箱拒绝公告归档夹具的 NTFS 硬链接 | 用原生临时目录复验真实归档语义。 |
| 两个解析后端用例硬性要求 README 直接列链接 | 解析后端审查检查当前文档入口和实际集成，修正失真的文档断言。 |
| 来源导出重构首轮改变了已冻结的版本不匹配错误 | 保留原诊断并加无需接触目录的拒绝用例。 |
| 原文端口复验发现声明正确而缓冲区不符的兼容后端 | 让流式散列观察绑定真实字节。拒绝引文范围外的等长篡改。 |
